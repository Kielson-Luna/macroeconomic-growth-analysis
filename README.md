# Análisis Macroeconómico de Crecimiento y Sostenibilidad Fiscal

Estudio comparado sobre determinantes del crecimiento económico a largo plazo, contabilidad de la productividad y sostenibilidad de los sistemas de pensiones en **España, Estados Unidos, Noruega, Bolivia y Marruecos**.

## Metodología y Herramientas
- **Modelos macroeconómicos:** Modelo de convergencia de Solow y Hechos Estilizados de Kaldor.
- **Análisis cuantitativo:** Descomposición empírica de la Productividad Total de los Factores (PTF).
- **Herramientas:** Ingesta y tratamiento de datos con Python en Google Colab.

## Contenido
- `Informe de crecimiento económico..pdf`: Documento completo con el análisis de las cinco economías.
- `codigo_analisis.ipynb`: Cuaderno interactivo con el código en Python para el procesamiento de datos y la generación de gráficos.
